# Runbookit

Miten-tehdään-ohjeet aiheittain. Komento kuuluu tänne, ei `CLAUDE.md`:hen, ellei sitä tarvita lähes joka keskustelussa.

| Tiedosto | Aihe |
|---|---|
| `ymparistot.md` | Datasetit, `.env.local`, tokenit, Sanityn taso, paikallisen ympäristön sudenkuopat |
| `testit.md` | Yksikkötestit, tarkistukset, e2e, saavutettavuus, Studion savutesti |
| `tuotantomuutokset.md` | Kaikki mikä kirjoittaa productioniin, kertaskriptien tila ja muutosloki |
| `migraatio.md` | Vanhan sivuston ja Blogspotin haku ja migraatio developmentiin |
| `yllapito.md` | Ylläpito-ohje ja PDF:t, brändikuvat, siivoukset, arvosanat, Sanity-tyypit |
| `seo.md` | URL-konventiot, ohjaukset, metadata, JSON-LD |
| `julkaisu.md` | Lisälista skillille `tyokalut:julkaisu` |
| `katselmointi.md` | Lisälista `reviewer`-agentille |

Kertaluonteiset skriptit ovat `scripts/kerta/`-kansiossa päivättyinä; tila `tuotantomuutokset.md`:ssä.
